Title

YAP/TAZ Bistable Mechanosensitive Switch: Reproducible Simulation Code, Model Repository, and Robustness Validation Suite

Description
-----------
This repository contains the full computational implementation, validation simulations, figures, and reproducibility materials for the manuscript:

  "A Bistable Mechanosensitive Switch Model Predicts Transient YAP/TAZ
   Disinhibition Enables Gingival Regeneration"
   John D. Stabler, Independent Researcher, Boca Raton, FL

Core Question Addressed
-----------------------
Can transient biochemical intervention (LATS1/2 inhibition) induce permanent
phenotypic change in mechanically static gingival tissue—and is this transition
robust to biological noise, imperfect drug pharmacokinetics, and spatial
heterogeneity across a tissue?

The model answers: yes, via a bistable YAP/TAZ switch produced by ultrasensitive
positive feedback through the YAP-actin-ECM loop, with a therapeutic window of
approximately 1.31–8.69 kPa.

Model Framework
---------------
The regenerative fraction R(t) evolves according to:

  dR/dt = α · f(S) · σ(R) · (1−R) − β · g(L) · (1−f(S)) · R

with stiffness activation:
  f(S) = exp(−(S − S₀)² / 2σ²)

and ultrasensitive Hill feedback:
  σ(R) = Rⁿ / (θⁿ + Rⁿ)

and drug modulation:
  g(L) = K_L / (L + K_L)

Default parameters: α=2.0 h⁻¹, β=0.5 h⁻¹, S₀=5 kPa, σ=2 kPa, θ=0.3, n=4.
Bistability requires n>1; saddle-node bifurcations bracket the therapeutic window.

How to Reproduce
----------------
  git clone https://github.com/RandolphPelican/yap-taz-sim
  cd yap-taz-sim
  pip install numpy scipy matplotlib
  python run_all_sims.py

No GPU required. Total runtime: <5 minutes on standard laptop hardware.
All figures reproduce from scratch.

Limitations (Documented for Reviewer Transparency)
---------------------------------------------------
This ODE model abstracts spatial heterogeneity, inflammation coupling, and
single-cell stochasticity. Specifically:

• The Hill feedback term σ(R) is phenomenological; it encodes the YAP-actin-ECM
  loop without resolving individual molecular species. Simulation 1 confirms the
  functional form is necessary; the exact n and θ were calibrated from literature.

• The stochastic simulation (Sim 4) reveals that at noise amplitude η=0.05
  (~5% of dR/dt), spontaneous crossing events are non-negligible (~1.8%/day
  in the bistable zone from fibrotic starts). This sets an honest lower bound
  on the required signal-to-noise ratio for reliable therapeutic switching.
  For high-copy transcriptional regulators like YAP/TAZ, η is likely lower.

• The ABM uses Euler-Maruyama spatial coupling and Moore neighborhood averaging,
  not a full PDE with diffusion coefficients. The spatial predictions are
  qualitative, not quantitative.

These limitations are documented in the manuscript Discussion section and do
not alter the core theoretical prediction.

Key Numerical Results
---------------------
Sim 1: Bistable window (WT)     : 1.27–8.73 kPa  (gap = 0.997)
       Bistable window (full KO): NONE            (gap = 0.000)
Sim 2: Min R_final across all washout scenarios: 0.967 (at t½=1h)
Sim 3: Final tissue regeneration: 100% (from 4×4 seed in fibrotic background)
Sim 4: Bimodal distribution at S=4 kPa confirmed; 77.9% regenerative cells
       Spontaneous switch rate: 1.78%/day at η=0.05
